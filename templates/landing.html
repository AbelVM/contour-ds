FAQ

The questions we get first.

Does Contour need a server?
No. Everything runs in the browser against the tiles you point it at. A server is only needed if you want to cache graphs between sessions.
Which tile sources are supported?
Anything that follows the OpenMapTiles schema and carries a routable profile. OpenFreeMap and Protomaps work out of the box.
Can I use it commercially?
Yes. The library is MIT licensed; only the tile source you query has its own terms.
