Design system for spatial interfaces

Contour — the shape of a map

A token-driven interface system for three kinds of page: a landing page that has to persuade, a documentation site that has to explain, and a dashboard that has to be read at speed. Ink-dark by default, daylight-ready by design, and built around the one curve that makes a map a map: the isoline.

Motion a reader can stop

prefers-reduced-motion is an operating-system setting, so it is not the mechanism WCAG 2.2.2 asks for: a reader cannot reach it for one part of one page, and most have never opened it. [data-motion] is the page's own switch. paused holds every animation in its scope on the frame it is on — a spinner stays mid-rotation and still means working. running overrides the media query; leaving the attribute unset gives the choice back to the system.

The same attribute is the seam for content that updates on a timer: when a live region stops being live, the producer that polls it should set data-motion="paused" too, because 2.2.2 covers auto-updating information, not only motion.

How to add a component

The contract a third party follows. A component is a CSS block in the right layer, a specimen in the guide, and a snippet the tool extracts.

  1. Add the block to the correct file: components.css, components-data.css, components-docs.css, components-landing.css or components-shell.css, inside @layer components.
  2. Name it .c-<block>, parts .c-<block>__<element>, variants .c-<block>--<variant>. No descendant selectors into another component.
  3. Use tokens only — no raw hex, no hard-coded durations. The census gate fails on an unread token; the family gate fails on a raw literal.
  4. Add a specimen in the guide section it belongs to, marked data-snippet if it is not a .ds-panel / .ds-spec.
  5. Run node tools/snippets.mjs to regenerate the disclosure, then node tools/check-tokens.mjs and node tools/stamp.mjs --check.

Coordinate precision .c-readout[data-precision]

Digits are not quality. RFC 7946 §3.1.10 is explicit — “the number of digits of the values in coordinate positions MUST NOT be interpreted as an indication to the level of uncertainty” — so a readout states its precision, reserves the column for it, and names the axis order, which §3.1.1 makes normative: longitude first, then latitude. The resolution column is DERIVED, and node tools/audit/component-inventory.mjs recomputes every row from one degree of latitude (≈111.32 km) divided by the decimal place, so a typo in this table fails the build rather than shipping a confident wrong number. A degree of longitude shrinks by the cosine of the latitude, so at Madrid it is ≈84.7 km, not 111.32. Six decimals is the value §11.2 quotes as “about 10 centimetres”.

Install the package, point it at a tile source, and compute your first route. Four lines, no server.

Your first route #

Call route() with a source, a destination and a tile URL. It returns the geometry, the cost and the engine that produced them.

route.js 
import { route } from 'omt-router';

const url = 'https://tiles.openfreemap.org/planet';
const r = await route([-3.7038, 40.4168], [-3.6937, 40.4101], 'car', url);

console.log(r.found, r.cost);

Tile preparation dominates

The first call fetches and parses every tile in range. The search itself takes milliseconds — budget for the graph, not the query.

Components · 23

Web components

Optional progressive enhancement. Load contour-wc.js after ds.css to use contour-* and contour-shadow-* custom elements that generate their scaffolding from attributes. Light-DOM elements use the cascade directly; shadow-DOM elements ship slots and adopted stylesheets for encapsulation.

Where each shape of the markup lives: §04–§22 show every block as the CSS an author writes by hand, and this section shows the same blocks as elements that generate it. The division is deliberate, not a migration left half-done. The raw markup is the contract a consumer copies, and it works with no script at all; this layer is the optional enhancement over that same contract, so a page can drop it and lose nothing but its attributes.

Reactivity: every component extends ContourBase, which snapshots the author's nodes and class on first connect. An attribute change restores that snapshot, re-runs render(), and re-wires behaviour via enhance(), so authored content and listeners survive while generated nodes are rebuilt. Form values are preserved across a re-render; render bodies use ensure() for update-or-create reactivity.

Composition: components never reach into one another. A host composes by nesting or slotted content, and interactive components emit bubbling contour:* CustomEvents (contour:change, contour:select, contour:copy, contour:remove, contour:page, contour:open/ contour:close) that a parent handles without coupling to internals. Shadow wrappers adopt the document's same-origin sheets once and share one parsed stylesheet across instances.

Reactivity, counted

One card, two ways to change it. Writing three attributes in turn rebuilds the card three times; the same three writes inside batch() rebuild it once. The count is the element's own renderCount, not a number this page keeps, so it cannot drift from what the layer did.
