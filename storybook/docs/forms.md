## What the guide says

Controls sized for the hand and the keyboard. Every input has a visible label, a visible focus state and room for an error message that explains, not scolds. A select keeps its native option list: the platform draws that, so it follows the operating system's theme rather than the page's.

Equivalent contour-* elements are catalogued in §23.

Autocomplete input with keyboard navigation. Type to filter, arrow keys to navigate, Enter to select, Escape to close.
