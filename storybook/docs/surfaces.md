## What the guide says

Cards are for things that are independently actionable. Information that only belongs to its group does not get a container — it gets space and a rule.

Equivalent contour-* elements are catalogued in §23.

Route calculation runs in single-digit milliseconds once the tile graph is built.

Catchment areas and travel-time bands, with inner breaks for context.

Every result exports as GeoJSON, ready for QGIS, ArcGIS or a paper map.

Used once per page. If two plates meet, one of them should be a card.

Borderless, indexed, ruled at the top. The counter-move to the card grid.

No routing server, no third-party API, no latency tax.

The same query always returns the same engine and result.

The end of the page: the brand, a line about what this is, and the links that stay reachable.

A design system for spatial interfaces. One set of rules for three surfaces.

Scroll container with content-visibility for performance. Virtualization logic is the consumer's responsibility — this provides the CSS containment and scroll behavior.
