## What the guide says

When a decision is not obvious, these decide it. They are ordered by how often they come up.

In a dark chart, elevation is expressed by surface lightness and a single hairline. Shadows are reserved for things that genuinely float: menus, dialogs, toasts.

Eighty-five percent of the interface is neutral. Tidal marks action and success, Plasma marks live data, Clay marks failure. Nothing is coloured decoratively.

Size and weight alone leave a page flat. Generous space around the thing that matters does the same job, without adding another colour or border.

IBM Plex Mono is reserved for data, coordinates, labels and code. If it is prose, it is set in IBM Plex Sans. The split makes machine-read data instantly distinguishable.

A control shows the action it performs, and the state it is in, before you touch it. Sort arrows, delta arrows, a copy button that becomes a tick. Affordance here means obvious.

A landing page, a documentation site and a dashboard read as the same product: the same tokens, the same type scale, the same hairline. Only the density changes.
