## What the guide says

Numbers are set in mono with tabular figures so columns align. Readouts use dotted rules instead of boxes, which keeps dense data calm — and no two series are ever separated by hue alone.

Eight hues separate by hue, not by lightness — so a line also carries a dash pattern, and the legend previews that pattern. No chart asks the reader to tell two colours apart, and every series clears 3:1 against every surface it can be drawn on (canvas, canvas-sunken, surface-1/2/3, surface-raised), in both themes.

Bars for magnitude, one hue per series. The same plot, axis and tooltip vocabulary as the line chart — only the mark changes.

2D density with isoline overlay — the signature motif as function. Marching squares over a real field, same algorithm as the generator. No other design system ships this.

Add data-chart-export to a chart to get an SVG download button. Exports vector graphics for reports and presentations.

A panel always says where it stands. Empty is not an error, live is not idle, and the error state says what to do next.
